# Picture portraits

One picture per suspect, named by the suspect's id: `0.webp` is Ada, `59.webp` is Mort (ids are in
`shared/roster.json`). WebP, JPEG (`.jpg`) or PNG, square, about 512 × 512.

A suspect with a picture here shows it on every card and on the wall; the rest keep their drawn portrait.
How to make them, and a prompt for each suspect: [docs/PORTRAITS.md](../../../../docs/PORTRAITS.md).
